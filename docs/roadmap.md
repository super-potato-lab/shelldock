# 功能路线图

## 当前版本

完成 FinalShell 风格的工作区及核心 SSH/SFTP/Linux 监控实现。当前界面按公开截图的区域结构与常用交互设计，未经过用户实际版本截图的逐像素对齐。

## 下一批

- 实际导出文件与各版本字段的兼容验证。
- 真实主机的终端、文件传输、监控和断线验收。
- 可选 shell 集成（OSC 7），批量操作与拖拽上传。
- 断点续传、重试、打包传输、ZMODEM。
- 进程详情、监听端口、Ping/Trace 与磁盘 I/O。
- 命令模板参数、更多编码、编辑保存的原子替换能力。
- SSH 代理/跳板、端口转发、RDP。
- 同步、备份冲突解决与加速服务端。

Rust 后端应独立于 UI 保持可测试；每个新增功能有明确的协议或文件格式验收，而非以静态按钮作为完成标准。
